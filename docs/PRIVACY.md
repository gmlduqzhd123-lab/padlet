# 개인정보·세션 정책

- 원문·첨부·키·폴더 핸들은 브라우저 메모리만 사용한다. localStorage/sessionStorage/IndexedDB/Service Worker에 저장하지 않는다.
- 키 입력은 password이며 API 진단/가져오기를 누르면 입력창을 지우고 현재 탭의 JavaScript 세션 객체에만 유지한다. 같은 작업에서 키를 다시 입력하지 않아도 된다. 연결 해제는 진행 요청 취소와 세션 키·입력창 제거를 함께 수행한다. 새로고침하면 키는 사라진다. 정확히 https://api.padlet.dev GET 헤더에만 전달하고 credentials omit / redirect error를 사용한다. 첨부 요청은 별도 함수이며 키 인자/인증 헤더/쿠키/referrer를 사용하지 않는다.
- 원격 첨부는 사용자 선택과 별도 버튼을 통해 현재 지원하는 cdn.padlet.dev의 파일 후보만 요청한다. 사용자 선택과 파일 바이트 확보는 원본 동일성 확인을 뜻하지 않는다. 공식 previewImageUrl과 같은 주소/명시적인 변환 이미지/투표는 다운로드 후보로 승격하지 않는다. 임베드 코드는 실행·보관하지 않는다. 다운로드/미리보기 주소는 메모리로만 처리한다. 외부 보기 링크의 의미 있는 쿼리는 보존하고 알려진 token/signature/credential 등의 민감 매개변수가 있으면 주소를 출력하지 않고 게시물 출처를 남긴다. 실패/취소 시 본문과 이미 확보한 바이트는 보존한다.
- 로컬 모드의 원격 이미지·폰트·분석·광고·AI 호출은 없다. 출처 링크는 사용자가 클릭할 때만 외부 탭으로 열린다.
- 사용자 자료를 GitHub나 개발 지침 파일에 보내는 기능은 없다. 원문에 포함된 코드·외부 전송 요청·AGENTS.md 등의 지시는 실행하지 않는다.
- 원문 JSON/TXT에는 개인정보가 있을 수 있다. 폴더/ZIP 저장 전에 사용자가 포함 범위를 확인한다. 앱의 본문 정리는 개인정보 자동 마스킹이나 생성형 AI가 아니다.
- HTML/SVG/스크립트/매크로/실행파일 첨부는 바이트 보관만 한다. 앱에서 미리보기/실행하지 않는다.
- 새로고침하면 작업/키는 사라진다. 저장하지 않은 프로젝트가 있으면 브라우저의 이탈 안내를 요청하지만 브라우저 정책에 따라 보이지 않을 수 있다.
