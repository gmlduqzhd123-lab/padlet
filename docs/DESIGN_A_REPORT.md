2026-10-15 후속: 사용자가 공개 배포를 요청했다. 최신 원격 main의 앱 설치·QR·공유 메타데이터·공통 하단 문구를 보존하여 병합했고, 기존 회귀 39개/가상 API 47개 및 확장 디자인 검수 8개를 재실행해 PASS를 확인했다. 아래의 미배포 문구는 10월 9일 당시 기록이다. 이번 배포 결과는 `DESIGN_A_DEPLOYMENT_REPORT.md`를 따른다.

작업일: 2026-10-09. 사용자의 ‘1안으로 가자’ 선택에 따라 기존 정적 앱에 적용했다. 원격 커밋·푸시·배포는 이번 작업에서 수행하지 않았다.

## 변경 파일과 구현

- `index.html`: 왼쪽 단계 메뉴, 모바일 상단 메뉴, 키보드 건너뛰기 링크, 링크/파일 가져오기 경로, 서재 제목과 CSS 종이 장식, 빈 자료 안내. 기존 입력·버튼 ID, CSP, 자산 상대경로 유지.
- `assets/css/app.css`: 크림 배경, 세이지·올리브 버튼, 종이 표면, 시스템 바탕 제목, 반응형 배치, 선택 게시물 강조, 포커스 표시. 외부 폰트·이미지·SDK 없음.
- `assets/js/app.js`: 화면 위치에 따른 단계 메뉴 표시, 현재 상세 게시물 강조, 필터 결과 없음 안내. 수집·키·원문·첨부·저장 처리는 기존 로직 유지.
- `tests/design.cjs`: 실제 앱의 키보드·경로 이동·가상 가져오기·선택·저장 상태·반응형 검수와 화면 캡처.
- `PRD.md`, `TASKS.md`, `ACCEPTANCE.md`: 사용자 선택과 실제 검수 범위 반영.

## 직접 실행한 시험

환경: Windows, Node 테스트 도구, Playwright Chrome 154.0.8037.98. 테스트용 임시 localhost 서버에서 `/repo/index.html`로 실행했다. 운영 시 Node 서버나 빌드가 필요하지 않다.

| 명령 | 결과 | 입력과 확인 범위 |
|---|---|---|
| `node tests/api.cjs` | PASS 47개 | 가상 API 키·모의 공식 응답. 키 재사용/해제·취소·첨부 분리·CSP·부분 실패·ZIP 출력 |
| `node tests/run.cjs` | PASS 39개 | 가상 100개 CSV/XLSX·첨부 ZIP, 원문·정리본, 파일 연결, ZIP 독립 해제, 악성 입력 방어, 모의 폴더 저장, 대용량, 오프라인 HTML |
| `node tests/design.cjs` | PASS 7개 | 키보드 건너뛰기, 가져오기 경로, 필터·선택, 저장 단계, 390/768/1024px, 원격 요청·페이지 오류 0건 |
| `git diff --check` | PASS | 공백 오류 없음. Git 줄바꿈 안내는 발생 |

최초 디자인 시험에서 페이지 맨 아래의 저장 단계 활성 표시가 시간 초과로 실패했다. IntersectionObserver 방식을 화면 위치 계산과 하단 도달 확인으로 수정하고 같은 시험을 재실행해 통과했다. 미해결 시험 실패는 없다.

로컬 회귀와 가상 API 시험 후 메뉴 계산만 수정했으며, 그 수정은 디자인 시험 재실행으로 검증했다. 모의 시험을 실보드 수집 성공으로 표시하지 않는다.

## 미검증과 사용 방법

- NOT_RUN: 실제 계정/API 키/승인 보드·Pages 출처 실연동. 기존 미검증 표시는 유지한다.
- NOT_RUN: 실제 사용자 OS 폴더 승인·디스크 저장 확인. 회귀 시험은 모의 폴더 핸들이다.
- NOT_RUN: 새 디자인의 원격 푸시와 GitHub Pages 배포. 현재 공개 주소는 기존 배포본이다.
- 접근성 전면 인증·실기기 터치 검수는 수행하지 않았다.

로컬 `index.html`을 기존 정적 미리보기로 연다. 링크 입력 → 최초 키 입력 → 게시물 가져오기 또는 내보낸 CSV/XLSX/JSON과 첨부 ZIP 가져오기 → 자료 선택·첨부 확인 → 원문/정리본 비교 → 개인정보 확인 → 폴더/ZIP 저장 순서다. 미지원 호스트는 로컬 파일 추가·수동 연결을 사용한다. ZIP은 생성과 다운로드 시작만 표시하며 디스크 저장 확인과 구분한다.

다음 공개 반영에는 사용자 배포 요청이 필요하다. 실연동 검수에는 유효한 API 자격과 승인된 테스트 보드가 필요하다.
