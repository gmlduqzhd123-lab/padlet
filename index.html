게시글은 읽기 좋은 문서로, 첨부자료는 출처가 연결된 파일로 정리합니다.

1. 링크로 가져오기

링크 → 최초 키 입력 → 게시물 가져오기 → 자료 선택·첨부 확보 → 글 정리 → 폴더/ZIP 저장

공식 API에는 유료 이용 자격·대상 보드 관리자 권한·브라우저 접근 허용이 필요합니다. 실제 계정 연결은 미검증입니다. 

링크만으로 게시물을 읽지는 않습니다. 주소 확인 후 API 키로 연결하거나, 키 없이 내보낸 파일을 가져오세요.
API 키 없이 CSV / XLSX · 첨부 ZIP 가져오기
최초 API 키 입력 · 현재 탭에서만 유지

키를 입력한 후 위의 ‘게시물 가져오기’를 누르세요. 같은 탭에서 재사용하며 새로고침하면 사라집니다. 연결 해제 시 진행 요청과 키를 지웁니다.

또는, 내보낸 파일로 정리하기

CSV / XLSX / 표준 JSON + 첨부 ZIP 또는 개별 파일. 원격 첨부는 자동 요청하지 않습니다.

ZIP 경로와 실제 해제 바이트를 검사합니다. HTML·SVG·실행파일은 실행하지 않습니다.
