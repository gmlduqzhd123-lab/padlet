📁 내보낸 파일로 정리하기

패들렛에서 내보낸 엑셀(XLSX)·CSV·JSON 파일과 첨부 ZIP을 올리면 버튼 클릭 없이 즉시 정리합니다.

💡 패들렛에서 파일 받는 법
1 패들렛 우측 상단 [↗ 공유] 클릭 → 2 [내보내기(Export)] 메뉴 → 3 [엑셀(XLSX) 또는 CSV로 저장]
📥
여기에 게시물 파일(CSV·XLSX)과 첨부 ZIP을 함께 끌어다 놓으세요 또는 아래에서 파일을 선택하면 버튼을 누르지 않아도 즉시 정리 목록이 열립니다
⚙️ 글자 깨짐(인코딩) · 엑셀 시트 · 열 매핑 상세 설정

방법 B · 공식 API 연결

🔗 패들렛 링크로 가져오기

패들렛 보드 주소와 API 키로 게시물 목록과 첨부 정보를 읽어옵니다.

링크만으로 게시물을 읽지는 않습니다. 주소 확인 후 API 키로 연결하거나, 키 없이 내보낸 파일을 가져오세요.
👉 API 키 없이 CSV / XLSX · 첨부 ZIP 가져오기
🔑 최초 API 키 입력 · 현재 탭에서만 유지

키를 입력한 뒤 ‘게시물 가져오기’를 누르세요. 같은 탭에서 유지되며 새로고침하면 지워집니다.

연결 해제 상태 · 키 없음

🛠️ 고급 연결 진단 및 보드 ID 직접 입력 
아직 API 요청을 보내지 않았습니다. 링크와 최초 키 입력 후 ‘게시물 가져오기’를 누르세요. 실계정 검증 기록은 아직 없습니다.
